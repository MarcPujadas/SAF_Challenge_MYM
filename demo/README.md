# Demo en video de SAFi

Aquesta carpeta inclou les instruccions; **no conte un video enregistrat**. Per a la presentacio, graveu una captura real amb OBS o Windows Snipping Tool: inici de l'app, serveis, heatmap, suggeriment, reserva, chatbot i dashboard. Durada recomanada: 90–120 segons. No ensenyeu tokens al terminal ni dades privades del SAF. Indiqueu quan el seed utilitza dades **SINTETIQUES**. Desa el fitxer final com `demo_safi.mp4` quan l'equip l'hagi gravat i verificat.
